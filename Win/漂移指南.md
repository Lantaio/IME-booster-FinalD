# 漂移指南

从v9.85版开始此插件实现了可以更改触发热键和任意组合漂移配置列表的功能。

## 更换触发热键

想更换某对热键所绑定的漂移配置映射表，修改MySettings\Shortcut.ahk文件中`Global SHIFT_MAP`或`Global LWIN_SHIFT_MAP`所绑定的漂移映射列表。

## 组合漂移配置映射表

要修改漂移配置列表组合，修改`Global SHIFT_MAP`或`Global LWIN_SHIFT_MAP`所调用的`assembleMaps`函数的参数列表。例如：如果想让数字先漂移为下标数字，再漂移为上标数字，只需调换`Global LWIN_SHIFT_MAP`常量`assembleMaps`函数的参数列表中`SuperscriptNumber`和`SubscriptNumber`的顺序。另外，如果不需要圆圈数字，可以直接删除参数列表中的`CircledNumber`。

```AutoHotkey
Global LWIN_SHIFT_MAP := assembleMaps("Number", "SuperscriptNumber", "SubscriptNumber", "RomanNumber", "CircledNumber", "English", "Greek")  ; 修改前
Global LWIN_SHIFT_MAP := assembleMaps("Number", "SubscriptNumber", "SuperscriptNumber", "RomanNumber", "English", "Greek")  ; 修改后
```

* `assembleMaps`函数的参数列表中每个字符串对应MySettings文件夹中同名的漂移配置映射表YAML文件，省略了`.yaml`后缀。关于如何自定制漂移配置映射表，请参考[漂移映射表自定制说明](漂移映射表自定制说明.md)，以及MySettings文件夹中各个YAML文件。
* 多个映射表组合时按先后顺序依次合并，因此建议在组合时按标点符号的使用频率高低排列映射表名。
* 前面的`"Number", "SuperscriptNumber", "SubscriptNumber", "RomanNumber", "CircledNumber"`是几个数字漂移配置映射表按顺序组合。其中`"Number", "SuperscriptNumber", "SubscriptNumber"`3个映射表只有`Left`部分，表示由所绑定的热键的左边按键触发。假如想将下标数字改为用右边的热键触发，将SubscriptNumber.yaml文件中的`Left`修改为`Right`即可。
* `"RomanNumber"`罗马数字漂移只有`Right`部分，表示由所绑定的热键的右边按键触发。 `"CircledNumber"`圆圈数字既有`Left`部分，又有`Right`部分，表示左右两边都会按顺序和其它数字映射表合并。
* 后面的`"English", "Greek"`是字母按键漂移映射表。因为它们只有字母按键，没有数字键，所以和前面的数字漂移映射表在先后顺序上没有必然关系，可以放在数字漂移映射表前面。另外，`English`映射表只有`Left`部分，而`Greek`映射表只有`Right`部分，因此它们的先后顺序也不会影响最终的组合结果。
